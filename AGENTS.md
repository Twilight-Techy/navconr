# Project working instructions

Before project work, read these files in order:

1. `docs/README.md`
2. `docs/RULES.md`
3. `docs/MEMORY.md`
4. The relevant milestone in `docs/IMPLEMENTATION_PLAN.md` and tasks in `docs/TASKS.md`.

Follow the project rules within the user's authorized scope. Treat the implementation plan as a living plan, not proof that code exists. Record task progress in `docs/TASKS.md` and durable decisions, evidence, and handoff context in `docs/MEMORY.md`.

The original project discussion and dumps are local-only history in `context/` and are excluded from Git. Preserve them when present; public clones may not contain them. Never commit the context directory or its local integrity receipt.

# Licensing

Navconr is open source under the [MIT license](LICENSE), copyright 2026 Ibrahim Makanjuola. Dependencies retain their own licenses and notices.

The license follows the [Open Source Initiative's MIT template](https://opensource.org/license/mit). Python and inspector package metadata declare MIT, and Python distributions and research bundles include the license file.

Historical artifact receipts describe earlier builds and may record an unresolved license. The current license is defined by `LICENSE` and the package metadata. Package-registry identity, third-party dependency/asset review, research acceptance, and paper submission remain separate gates; see [release guidance](docs/RELEASE.md).

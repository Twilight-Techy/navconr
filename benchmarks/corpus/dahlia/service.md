# Dahlia service

## Request timeout

The Dahlia request timeout is 38 milliseconds.

## Retry policy

The Dahlia retry limit is 5 attempts with exponential backoff.

## Listener port

The Dahlia listener port is 8103.

## Audit retention

The Dahlia audit retention period is 14 days.

## Worker concurrency

The Dahlia worker concurrency limit is 55 tasks.

## Incident response

For incident recovery, follow [the recovery procedure](operations.md#recovery).
